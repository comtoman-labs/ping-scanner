# ⚡ Ping Scanner (고속 멀티스레드 네트워크 IP 핑 스캐너)

PySide6 기반의 가볍고 직관적인 **고속 멀티스레드 네트워크 IP 핑 스캐너 & 장비 탐색 도구**입니다.  
사설 네트워크 내 활성화된 장비(PC, 서버, 프린터, IoT 장비 등)를 빠르게 검색하고, **ARP를 통한 MAC 주소 확인**, 호스트 이름 조회 및 결과 내보내기(CSV)를 지원합니다.

---

## 🌟 주요 기능

1. **🚀 초고속 멀티스레드 스캔**
   * 최대 256개 스레드 동시 실행으로 C클래스(254개 IP) 기준 수 초 만에 스캔 완료
   * 타임아웃(100ms ~ 10,000ms) 및 스레드 수 자유 조절 지원
   * 스캔 중 일시정지(Pause) 및 중지(Stop) 지원

2. **🎯 유연한 IP 대역 입력 지원**
   * **CIDR 표기법**: `192.168.0.0/24`, `10.0.0.0/16`
   * **범위 표기법**: `172.16.10.1-254`, `172.16.10.1-172.16.11.20`
   * **다중/혼합 입력**: `192.168.0.1, 192.168.0.10-20, 10.0.0.1`
   * 프로그램 시작 시 **현재 PC의 네트워크 대역 자동 감지**

3. **🔍 방화벽(ICMP 차단) 장비 탐색 (ARP 기반 MAC 조회)**
   * Windows `SendARP` API를 탑재하여 ICMP 핑에 응답하지 않는 보안 장비도 MAC 주소로 활성화 여부(주황색 표시) 검출

4. **🖥️ 실시간 편의 기능**
   * **켜진 장비만 보기**: 오프라인 장비 숨김 필터
   * **실시간 검색창**: IP, 호스트명, MAC, 메모 키워드로 즉시 필터링
   * **컬럼 정렬**: 상태, IP(숫자 정렬), 응답속도, TTL, MAC, 의견별 오름/내림차순 정렬
   * **다크 모드 / 라이트 모드 전환**: 상단 토글 버튼으로 깔끔한 테마 변경
   * **의견(메모) 작성**: 테이블 내 셀을 더블 클릭하여 장비별 메모 직접 입력

5. **🖱️ 우클릭 컨텍스트 메뉴**
   * 선택 장비 다시 핑(Re-ping)
   * IP 복사 / MAC 주소 복사
   * 웹 접속 바로가기 (`http://IP`, `https://IP`)

6. **💾 CSV 파일 내보내기**
   * 스캔 결과 및 작성한 메모를 CSV 파일로 저장

## 🚀 실행 및 빌드 방법

### 1. 개발 및 일상 실행
가상환경 활성화 후 실행하거나 **`run.bat`** 파일을 더블 클릭합니다:
```bash
# 의존성 설치
pip install -r requirements.txt

# 실행
python ping_scanner.py
```

### 2. 독립 실행 파일 (.exe) 빌드
**`build_exe.bat`** 파일을 실행하면 자동으로 PyInstaller를 통해 독립 실행 프로그램이 생성됩니다:
* 빌드 결과: `dist/PingScanner.exe` (약 46MB 단일 파일)
* **배포 권장**: 소스 코드에는 `.exe`를 커밋하지 않고, GitHub 저장소의 **Releases** 탭에 업로드하여 배포합니다.
